# AI Business Launcher

AI Business Launcher is a SaaS platform that enables small businesses to create and publish professional websites using AI with minimal user input.

## Vision

A business owner should be able to:

1. Describe their business
2. Click Generate
3. Preview their website
4. Publish it

The platform handles content generation, layout selection, SEO, and deployment.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL (planned)
- Prisma (planned)
- OpenAI API (planned)
